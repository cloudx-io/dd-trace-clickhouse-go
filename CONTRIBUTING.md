# Contributing

This library is meant to be useful to others. It primarily exists as working evidence for the [proposal to add ClickHouse native API tracing to dd-trace-go](https://github.com/DataDog/dd-trace-go/discussions/5332). The long-term goal is to upstream it there.

Bug reports and fixes that preserve the current scope are welcome. Run `go test ./...` and `golangci-lint run` before submitting a fix. No new features will be accepted in this repository. Propose new behavior in the upstream discussion.
